# ProFlow Webview Analysis

This directory contains the webview analysis components for ProFlow, including the handling and validation of graph data used within the webview.

## Static JS assets

The static JavaScript assets required for the webview are located in this directory. These assets include scripts for rendering and interacting with the graph data within the webview.
They are created from the proflow_webview source files, which are then processed and optimized for use within the webview environment.
